# 销售计划管理目标流程

维护可填报商品 → 配置填报窗口 → 销售保存草稿/提交 → 分级审核 → 确认执行 → 订单匹配与分析 → 周期完成归档。

线下月计划省区商品，线下周计划省区客户商品，省区提交后大区汇总、中心汇总、严总确认。线上月周按渠道商品，丹总确认。各级原始值、汇总快照及意见保留。

确认后增减：原计划 → 加急差异和原因、附件 → 线上丹总/线下严总OA审批 → 通过生成新版本，驳回原版不变。

异常：截止保存草稿或授权补报；停售商品禁止新报；历史缺失待同步；订单未匹配或多匹配由审核角色处理；审批冲突要求重新发起；存储失败说明原因并保留页面输入。
