# PRD：代理发货管理

**状态**：Draft  
**版本**：V0.1  
**日期**：2026-05-04  
**适用对象**：平台订单运营、代理/运营中心、平台审核、平台供应链、管理者  
**关联需求文档**：`../04-需求管理/05-代理发货管理功能梳理.md`  
**关联主线**：`../05-产品方案/03-运营中心三方履约补货PRD.md`

## 1. 问题陈述

客户订单由代理/运营中心就近发货时，平台需要管理“谁来发、什么时候接单、什么时候发货、物流是否正常、实际发了多少、是否有凭证、后续是否补货或对账”。当前这些信息如果依赖线下沟通，会导致进度不可见、异常处理慢、数量难核对、责任难追溯。

本功能通过新增 `代理发货单`，把客户订单和代理履约过程连接起来，形成平台可管、代理可操作、结果可追溯的发货管理闭环。

## 2. 目标与成功指标

| 目标 | 指标 | V1 目标 |
| --- | --- | --- |
| 提升代理发货过程透明度 | 代理发货单关键字段完整率 | 100% |
| 降低线下沟通成本 | 线下催接单/催发货次数 | 试运行期明显下降 |
| 提升履约时效 | 平均接单时长、平均发货时长 | 低于人工沟通模式 |
| 降低发货差错 | 数量不一致、重复派单次数 | 试运行期目标为 0 |
| 支撑补货/对账 | 后续单据关联完整率 | 100% |

## 3. 非目标

V1 不做以下内容：

- 不做全自动代理最优分配。
- 不做自动财务结算。
- 不做复杂库存批次、温层和效期管理。
- 不强依赖第三方物流轨迹自动同步。
- 不做客户侧代理品牌露出策略。
- 不做售后责任自动判定。

## 4. 用户与场景

### 4.1 平台订单运营

作为平台订单运营，我希望可以把订单派给合适代理，并实时看到代理是否接单、是否发货、是否异常，以便及时催办、改派或关闭。

### 4.2 代理操作员

作为代理操作员，我希望只看到分配给我的发货任务，并能快速接单、拒单、填写物流和上传凭证，以便完成发货。

### 4.3 平台审核人员

作为审核人员，我希望查看发货凭证和签收凭证，判断是否可以进入补货、对账或完成状态。

### 4.4 平台供应链

作为供应链人员，我希望看到代理发货单的客户订单、实际发货数量和凭证依据，以便准确安排补货。

### 4.5 管理者

作为管理者，我希望看到代理发货订单量、接单时效、发货时效、拒单率和异常率，以便评估代理履约质量。

## 5. 方案概述

系统新增 `代理发货管理` 模块。客户订单确认后，平台可根据商品、区域、代理服务能力和库存情况选择代理，并生成代理发货单。代理在自己的工作台中处理待接单、待发货、凭证驳回等任务。平台端集中监控代理发货单状态，并处理拒单、超时、缺货、物流异常、数量不一致等情况。

V1 推荐采用 `系统推荐 + 平台人工确认` 的派单方式，先保证业务可控和留痕完整，再逐步扩展自动分配能力。

## 6. 功能范围

### 6.1 本次范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 代理发货单 | 生成、列表、筛选、详情 | 承接客户订单到代理履约的过程 |
| 派单/改派 | 选择代理、确认派单、记录原因 | 平台操作 |
| 接单/拒单 | 代理确认或拒绝发货任务 | 拒单必须填原因 |
| 发货物流 | 填写物流、发货数量、上传发货凭证 | 支持部分发货 |
| 凭证处理 | 上传、审核、驳回、重传 | 可作为补货/对账依据 |
| 异常处理 | 缺货、超时、物流异常、数量不一致 | 支持备注、改派、关闭 |
| 日志 | 关键操作留痕 | 派单、接单、发货、审核、异常均记录 |

### 6.2 不包含范围

- 自动结算账单。
- 代理履约评分模型。
- 物流轨迹接口深度集成。
- 完整代理库存系统。
- 客户侧展示策略调整。

## 7. 功能设计

### 7.1 代理发货单生成

| 规则 | 说明 |
| --- | --- |
| 来源 | 客户订单确认后，由平台选择代理发货 |
| 生成条件 | 订单状态正常、商品支持、区域匹配、代理状态正常 |
| 生成结果 | 生成代理发货单，关联客户订单和商品明细 |
| 派单方式 | V1 支持系统推荐、平台人工确认 |
| 重复校验 | 同一订单明细同一数量不能重复派单 |

验收标准：

- 满足条件的客户订单可以生成代理发货单。
- 代理发货单必须关联来源客户订单和商品明细。
- 不满足条件的订单不能进入代理发货。
- 重复派单时系统应阻断或提示。

### 7.2 平台派单与改派

| 功能 | 说明 |
| --- | --- |
| 选择代理 | 展示代理名称、服务区域、可发商品、库存/可发量、承诺时效 |
| 确认派单 | 生成待接单任务 |
| 改派代理 | 拒单、超时、缺货时可改派 |
| 派单备注 | 记录人工选择原因 |

验收标准：

- 平台可以选择代理并派单。
- 改派必须记录原因。
- 改派后原任务不可继续被代理发货，或必须明确进入已改派状态。

### 7.3 代理接单/拒单

| 功能 | 说明 |
| --- | --- |
| 待接单列表 | 代理只看自己的待接单任务 |
| 确认接单 | 状态变为待发货 |
| 拒绝接单 | 必须选择原因并填写说明 |
| 超时提醒 | 超过时限提醒代理和平台 |

验收标准：

- 代理只能操作自己名下发货单。
- 接单操作记录操作人和时间。
- 拒单必须有原因。
- 拒单后平台可以改派或退回原履约流程。

### 7.4 发货与物流

| 功能 | 说明 |
| --- | --- |
| 填写物流 | 物流公司、物流单号、发货时间、发货件数 |
| 商品数量 | 按 SKU 填写实际发货数量 |
| 发货凭证 | 上传面单、出库照、装箱照等 |
| 部分发货 | 未发数量必须填写原因 |
| 修改物流 | 允许修改但必须留痕 |

验收标准：

- 已接单发货单可以填写物流并进入已发货。
- 物流公司和物流单号为空时不能提交。
- 实际发货数量不能超过派单数量。
- 部分发货必须记录未发原因。

### 7.5 凭证上传与审核

| 功能 | 说明 |
| --- | --- |
| 上传凭证 | 代理上传发货凭证或签收凭证 |
| 审核通过 | 平台确认凭证有效 |
| 审核驳回 | 必须填写驳回原因 |
| 重传凭证 | 代理按驳回原因重新上传 |

验收标准：

- 凭证支持查看上传人、上传时间和附件。
- 审核驳回必须展示原因。
- 凭证通过后发货单可进入已完成或待补货/待对账。

### 7.6 异常处理

| 异常 | 触发条件 | 处理方式 |
| --- | --- | --- |
| 代理拒单 | 代理选择拒绝接单 | 平台改派或退回原流程 |
| 接单超时 | 超过配置时限未接单 | 催办、改派 |
| 发货超时 | 接单后超过时限未发货 | 催办、改派、关闭 |
| 缺货 | 代理接单后反馈库存不足 | 部分发货、改派、退回总部 |
| 物流异常 | 物流停滞、退回、丢件 | 暂停完成，人工处理 |
| 数量不一致 | 派单、发货、签收数量不一致 | 人工复核 |
| 凭证异常 | 凭证不清晰或信息不完整 | 驳回重传 |

验收标准：

- 异常类型、说明、责任方和处理结果均有记录。
- 异常关闭后代理不能继续发货。
- 异常处理日志可追溯。

### 7.7 后续单据关联

| 功能 | 说明 |
| --- | --- |
| 补货关联 | 发货完成后可生成或关联补货单 |
| 对账关联 | 若业务需要，可预留对账单编号 |
| 来源追溯 | 后续单据可回查代理发货单 |

验收标准：

- 代理发货单可以展示关联补货单或对账状态。
- 后续单据必须能追溯客户订单、代理、商品和实际发货数量。

## 8. 状态设计

```text
待派单
  -> 待接单
    -> 已拒单 -> 待平台处理 -> 改派/退回原流程
    -> 待发货
      -> 部分发货
      -> 已发货
        -> 已签收
          -> 凭证待审核
            -> 凭证驳回 -> 待补充凭证
            -> 审核通过 -> 已完成
异常可从待接单、待发货、已发货、已签收阶段进入异常关闭
```

## 9. 权限设计

| 功能 | 平台订单运营 | 平台审核 | 平台供应链 | 代理 | 管理者 |
| --- | --- | --- | --- | --- | --- |
| 查看全部发货单 | 可 | 可 | 可 | 不可 | 可 |
| 查看本代理发货单 | 不适用 | 不适用 | 不适用 | 可 | 不适用 |
| 派单/改派 | 可 | 不可 | 不可 | 不可 | 可 |
| 接单/拒单 | 不可 | 不可 | 不可 | 可 | 不可 |
| 填写物流 | 可代操作 | 不可 | 不可 | 可 | 可代操作 |
| 上传凭证 | 可代操作 | 不可 | 不可 | 可 | 可代操作 |
| 审核凭证 | 不可 | 可 | 不可 | 不可 | 可 |
| 异常处理 | 可 | 不可 | 不可 | 不可 | 可 |
| 关联补货 | 可查看 | 可查看 | 可 | 不可 | 可 |

## 10. 数据与日志要求

### 10.1 必须留痕的操作

- 代理发货单生成。
- 平台派单、改派、撤回。
- 代理接单、拒单。
- 物流提交和修改。
- 发货凭证/签收凭证上传。
- 凭证审核、驳回、重传。
- 异常标记、备注、关闭。
- 关联补货单或对账单。

### 10.2 核心关联关系

```text
客户订单
  -> 代理发货单
    -> 代理接单记录
    -> 发货物流记录
    -> 凭证记录
    -> 异常记录
    -> 补货单/对账单
```

## 11. 页面设计要求

| 页面 | 目标 | 关键能力 |
| --- | --- | --- |
| 代理发货订单列表 | 平台集中处理代理发货 | 状态统计、筛选、表格、催办、导出 |
| 代理发货订单详情 | 查看完整链路 | 摘要、商品、物流、凭证、异常、日志 |
| 派单/改派弹窗 | 选择代理 | 推荐代理、服务区域、可发量、派单原因 |
| 异常处理抽屉 | 快速处理风险 | 异常类型、责任方、处理动作、备注 |
| 代理发货工作台 | 代理处理任务 | 待接单、待发货、凭证驳回、待补充 |
| 物流填写弹窗 | 提交发货 | 物流公司、单号、发货数量、凭证 |

## 12. 上线策略

### 12.1 V0.1 试运行

- 选择少量代理和商品试点。
- 平台人工派单，代理系统内接单和发货。
- 补货或对账先保留人工确认。

### 12.2 V1.0 正式上线

- 扩展稳定代理范围。
- 固化接单、发货、凭证、异常流程。
- 增加代理发货 SLA 统计和导出。

### 12.3 回滚标准

出现以下情况应暂停自动推荐或扩大试点：

- 代理库存准确性不足，拒单率持续过高。
- 代理发货时效低于原履约流程。
- 发货数量与客户签收数量频繁不一致。
- 凭证审核争议频繁。

## 13. 待确认问题

1. 前台菜单最终命名是否使用 `代理发货管理`？
2. 代理是否等同现有 `运营中心`，还是需要单独维护代理档案？
3. 客户订单是否支持拆单给多个代理？
4. 发货完成后进入补货、对账，还是两者都可能存在？
5. 是否需要代理移动端优先设计？
6. 是否接入物流轨迹接口？

## 14. 验收标准

- 平台可创建代理发货单并派给指定代理。
- 平台可查看所有代理发货单及状态统计。
- 代理只能查看和操作自己名下发货单。
- 代理可完成接单、拒单、填写物流、上传凭证。
- 拒单、部分发货、超时、物流异常可进入异常处理。
- 物流和凭证修改有日志。
- 代理发货单可追溯客户订单、商品明细、实际发货数量、物流、凭证和后续单据。
- 权限、状态和防重复规则符合本 PRD。
