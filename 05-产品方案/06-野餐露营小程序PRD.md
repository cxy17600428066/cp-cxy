## 1. 产品定位

野餐露营小程序面向城市周边休闲用户，提供营地预约、套餐购买、装备租赁和订单管理能力。V1 目标是让用户在一个移动端入口完成“找营地 -> 看详情 -> 选套餐 -> 加装备 -> 预约下单 -> 查看订单”的主链路。

## 2. 目标与指标

| 目标 | 指标 | V1 目标 |
| --- | --- | --- |
| 提高预约转化 | 详情页到预约页转化率 | 可追踪 |
| 降低决策成本 | 用户完成下单步骤数 | 5 步内 |
| 提高客单价 | 装备加购率 | 可统计 |
| 降低客服咨询 | 订单信息完整率 | 联系人、日期、时段完整 |
| 支撑运营复盘 | 营地和套餐销量 | 可按营地/日期查看 |

## 3. 非目标

- V1 不做真实微信支付接入。
- V1 不做真实地图导航，仅保留位置入口。
- V1 不做商户后台。
- V1 不做复杂会员等级和积分商城。
- V1 不做内容社区发布。

## 5. 页面设计

### 5.1 首页

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 顶部 | 城市、日期、天气提示 | 切换城市和日期 |
| 搜索 | 营地/区域/场景关键词 | 输入关键词进入列表 |
| 分类 | 营地预约、套餐、装备、活动 | 点击切换对应页面 |
| 推荐营地 | 封面、评分、距离、价格 | 点击进入详情 |
| 今日可约 | 套餐和剩余库存 | 点击进入预约 |

### 5.2 营地详情

| 区域 | 内容 |
| --- | --- |
| 场景封面 | 营地视觉、名称、标签 |
| 核心信息 | 距离、评分、适合人数、开放时间 |
| 设施 | 天幕、电源、卫生间、停车、宠物友好 |
| 套餐 | 推荐套餐、价格、包含内容 |
| 注意事项 | 天气、垃圾清理、押金、改期规则 |

### 5.3 预约页

| 字段 | 说明 |
| --- | --- |
| 营地 | 从详情页带入，可返回修改 |
| 日期 | 必填 |
| 时段 | 半日、全天、夜营 |
| 人数 | 成人、儿童 |
| 套餐 | 必选 |
| 装备 | 可选加购 |
| 联系人 | 姓名、手机号 |
| 备注 | 可选 |

验收标准：

- 未选择日期、时段或联系人时不能提交。
- 选择不同套餐和装备后价格明细同步更新。
- 提交后进入订单成功状态。

### 5.4 订单

| 状态 | 说明 |
| --- | --- |
| 待支付 | 已生成预约但未支付 |
| 待出行 | 已支付，待到场核销 |
| 已完成 | 已核销或活动结束 |
| 退款中 | 用户发起退款或改期 |

订单详情展示预约时间、营地地址、联系人、费用明细、核销码和售后入口。

## 6. 核心交互规则

- 首页默认展示用户最近城市和本周末日期。
- 营地卡片优先展示可预约、评分高、距离近的内容。
- 套餐价格按人数档展示，装备按件数计费。
- 预约页默认带入详情页选择的营地和套餐。
- 用户提交预约后生成模拟订单，状态为待支付或待出行。
- 小程序底部导航保持：首页、营地、预约、订单、我的。

## 9. 风险与待确认

- 是否自营营地，还是平台聚合商户。
- 是否需要押金和装备损坏赔付规则。
- 是否接入真实天气和地图能力。
- 是否支持到场前改期和部分退款。
- 是否需要 B 端商户接单和库存管理。
