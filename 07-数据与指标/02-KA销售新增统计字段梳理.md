# KA销售新增统计字段梳理

> 数据来源：`E:\cxy\99-附件与参考\F` 下 11 个销售数据工作簿；需求来源：`数据需求5.25(1).docx`。

## 1. 需求摘要

本次新增统计需求可以分为 5 组：

1. 新增大盘表：`KA大盘出货数据`
   - 系统每天出货数量、出货金额。
   - 支持按单品、按渠道、按数量、按金额统计。
   - 支持系统单品出货额与 POS 销售额对比。

2. POS 库存周转
   - 门店端库存周转天数。
   - 各大区、各单品库存周转天数，按数据日前 7 天平均销售计算。
   - 各大区库存周转天数超 60 天门店数排名。

3. 大润发专项
   - PSD，按数据日前 7 天平均。
   - 内区 / 外区占比。
   - 内区分布：江苏、上海、安徽、浙江各区总销金、排名、占比、门店数。
   - 各区域销金倒数 30 家门店，展示环比百分比、温层区分。
   - 单品销量、占比、销量排名、环比百分比。

4. 沃尔玛专项
   - 单品库存情况。
   - 单日 TOP10 销售金额门店。
   - 每日脱骨侠退货情况、当月累计退货情况。
   - 当月退货 / 当月该单品进货比例。

5. 华润专项
   - 按四个大区分布销售情况。

现有 IT 日报已覆盖：大盘销售额、销量、当月日均销量、库存、门店数、动销门店数及环比；品项销售 / 库存占比、销量、7 日趋势、周转天数；门店动销 TOP50 明细。

## 3. 建议新增统计字段

### 3.1 KA 大盘出货 / 销售总览

建议新增一张统一事实表或宽表，字段如下：

| 字段 | 口径 | 来源可行性 |
|---|---|---|
| 数据日期 | 销售 / 库存 / 出货发生日期 | 各系统均有日期字段 |
| KA 系统 | 永辉、盒马、华润、沃尔玛、大润发、比优特、家得福、天虹 | 从文件或系统映射表生成 |
| 大区 | 华北、华东、华南、西北等 | 华润、大润发可直接取；沃尔玛需关联门店表；其他系统需补门店区域映射 |
| 省区 / 省份 | 省份公司、省区公司，或由门店名称解析 | 华润可直接取；其他建议维护门店维表 |
| 门店编码 | KA 门店编码 | 除盒马部分缺门店编码外基本可取 |
| 门店名称 | KA 门店名称 | 各系统均可取 |
| 是否 DC | 标识 DC / 门店 | 永辉、盒马、天虹、比优特、家得福有字段；大润发分门店库存 / DC库存；沃尔玛需规则判断 |
| 商品编码 | KA 商品编码 | 各系统均可取 |
| 商品条码 | 国条码 / UPC | 多数系统可取；大润发部分缺国条码 |
| 商品名称 | KA 商品名称 | 各系统均可取 |
| 规格 | 商品规格 | 大润发、天虹、家得福、比优特等可取；部分系统需从品名解析 |
| 温层 | 常温 / 冷藏 | 大润发、沃尔玛报表中有明显常温 / 冷藏品项；建议通过商品维表维护 |
| 销售数量 | POS 销售数量 | 各系统均可取 |
| 销售金额 | POS 销售额，优先含税口径 | 各系统均可取，但含税 / 未税需统一 |
| 出货数量 | 进货、入库、日收、月收、待收等代表的到货 / 出货数量 | 盒马、家得福、大润发可算；其他系统缺稳定出货字段 |
| 出货金额 | 出货金额 / 进货金额 | 家得福有含税进货金额；盒马、大润发金额口径不完整，需确认 |
| 渠道 | 线下、线上及细分到家平台 | 大润发、天虹可直接拆分；华润有线上字段；其余系统暂只能汇总 |
| 库存数量 | 门店库存 + DC 库存可拆分 | 多数系统可取 |
| 在途数量 | 在途 / 采购在途 / 待收 | 永辉、盒马、沃尔玛、大润发可取 |
| 退货数量 | 退货数量 | 盒马有退货数量；沃尔玛当前源表缺；大润发仅 DC 待退库存，不等于退货发生 |
| 退货金额 | 退补金额 / 退货金额 | 家得福有含税退补金额；其他系统需补源 |

### 3.2 POS 与出货对比字段

| 字段 | 计算口径 |
|---|---|
| 单品 POS 销售额 | 按 `数据日期 + KA系统 + 商品编码 / 条码` 汇总 POS 销售金额 |
| 单品 POS 销售数量 | 同维度汇总 POS 销售数量 |
| 单品出货额 | 同维度汇总出货 / 进货金额 |
| 单品出货数量 | 同维度汇总出货 / 进货数量 |
| 出货 - POS 金额差 | 单品出货额 - 单品 POS 销售额 |
| 出货 / POS 金额比 | 单品出货额 / 单品 POS 销售额 |
| 出货 / POS 数量比 | 单品出货数量 / 单品 POS 销售数量 |

注意：当前数据里“出货”并非所有 KA 都具备。建议先把该模块标成“有出货源的 KA 可计算”，不要强行用库存变化倒推出货。

### 3.3 库存周转字段

| 字段 | 计算口径 |
|---|---|
| 近 7 日平均销量 | 数据日前 7 天销售数量合计 / 7；建议不含数据日，口径为 D-7 至 D-1 |
| 门店库存数量 | 数据日门店端库存数量，不含 DC |
| DC 库存数量 | 数据日 DC 库存数量 |
| 总库存数量 | 门店库存 + DC 库存 |
| 门店库存周转天数 | 门店库存数量 / 近 7 日平均销量 |
| 总库存周转天数 | 总库存数量 / 近 7 日平均销量 |
| 是否周转超 60 天 | 门店库存周转天数 > 60 |
| 超 60 天门店数 | 按大区、商品统计周转超 60 天且门店库存 > 0 的门店数 |
| 超 60 天门店数排名 | 在各大区内按超 60 天门店数降序排名 |

边界规则建议：

- 近 7 日平均销量为 0 且库存 > 0：周转天数记为 `9999` 或 `无动销库存`，不建议显示为除零错误。
- 近 7 日平均销量为 0 且库存 = 0：周转天数为空。
- 是否 DC 必须先统一，否则会把仓库库存误算进门店周转。

### 3.4 PSD 字段

| 字段 | 计算口径 |
|---|---|
| PSD_当日 | 当日销售数量 / 当日有库存门店数，或沿用现有日报 PSD 口径 |
| PSD_近 7 日 | 近 7 日销售数量合计 / 近 7 日有库存门店数日均 |
| 动销门店数 | 当日销售数量 > 0 的门店数 |
| 有库存门店数 | 数据日门店库存 > 0 的门店数 |

建议明确 PSD 分母：如果现有日报以“已有门店库存门店数”为分母，新增字段也应沿用，避免前后口径不一致。

## 4. 专项需求拆解

### 4.1 大润发

可直接新增：

| 字段 | 可用源 | 说明 |
|---|---|---|
| PSD_近 7 日 | `销售数据源` + `门店库存` | 按数据日前 7 天平均销售计算 |
| 渠道销量 / 销额 | `销售数据源` | 已有线下、线上、优鲜、淘鲜达、饿了么、B2B、京东到家、美团、TCC、猫超、社区团购等 |
| 单品销量占比 | `销售数据源` | 单品销量 / 当前筛选范围总销量 |
| 单品销量排名 | `销售数据源` | 按销量降序 |
| 单品销量环比 | `销售数据源` | 当前周期销量 / 上周期销量 - 1 |
| 区域销金倒数 30 门店 | `销售数据源` | 按区域 + 门店汇总销售额后升序取 30 |
| 库存周转天数 | `门店库存` + `销售数据源` | 库存 / 近 7 日平均销量 |

需要补充或明确：

- 内区 / 外区没有在当前源表中看到结构化字段，需要门店维表维护。
- 江苏、上海、安徽、浙江等省份字段没有在大润发销售源表中直接出现，建议新增门店省份 / 区域维表。
- 温层建议通过商品维表维护，当前日报文本里能看到常温 / 冷藏，但源数据未必每行都有温层字段。
- 大润发三份文件分别是华北、华南、华东，若要全国大润发汇总，需要统一合并并增加 `大润发区域` 字段。

### 4.2 沃尔玛

可直接新增：

| 字段 | 可用源 | 说明 |
|---|---|---|
| 单品库存数量 | `数据源.Curr Str On Hand Qty` | 可按商品、门店、日期汇总 |
| 单品在途库存 | `数据源.Curr Str In Transit Qty` | 可按商品、门店、日期汇总 |
| 单日 TOP10 销售金额门店 | `数据源.POS Sales` | 按数据日 + 门店汇总后取 TOP10 |
| 门店大区 / 小区 | `5.22-5.31沃尔玛销售数据.xlsx` 的 `门店` sheet | 需要用店号关联新版数据源的 Store Nbr |

当前不能直接满足：

- 每日退货情况：新版 `数据源` 未见退货数量 / 退货金额字段。
- 当月累计退货：缺退货发生数据。
- 当月退货 / 当月该单品进货比例：缺退货和进货字段。`Curr Str In Transit Qty` 是在途库存，不等于进货；不建议替代。

建议向沃尔玛补取：

- `退货日期`、`门店号`、`商品编码 / UPC`、`退货数量`、`退货金额`。
- `进货日期`、`门店号`、`商品编码 / UPC`、`进货数量`、`进货金额`。

### 4.3 华润

可直接新增：

| 字段 | 可用源 | 说明 |
|---|---|---|
| 四大区销售数量 | `华北销售`、`华东销售`、`西北销售`、`华南销售` | 文件内已按大区拆分 |
| 四大区销售金额 | 同上 | 统一 `销售金额` / `销售 / 金额` 字段名 |
| 四大区线上销售数量 / 金额 | 同上 | 各销售 sheet 有线上销售字段 |
| 四大区库存数量 | 对应库存 sheet | 华南库存当前只有表头，数据不足 |
| 省份公司销售 | 销售表 `省份公司` | 可进一步下钻 |

风险点：

- 华南库存 sheet 目前只有 1 行表头，缺库存明细，无法计算华南库存周转。
- 华润销售字段命名不一致，如 `销售数量` 与 `销售 / 数量`，清洗时要做字段别名映射。

## 5. 优先级建议

### P0：先做统一口径和可直接上线字段

1. 统一销售事实表：日期、系统、门店、商品、销售数量、销售金额。
2. 统一库存事实表：日期、系统、门店 / DC、商品、库存数量、在途 / 待收。
3. 新增库存周转天数、超 60 天门店数排名。
4. 新增单品销量、销售额、占比、排名、环比。
5. 新增沃尔玛单品库存和单日 TOP10 门店。
6. 新增华润四大区销售分布。

### P1：依赖维表后上线

1. 大润发内区 / 外区占比。
2. 大润发江苏、上海、安徽、浙江内区分布。
3. 大润发各区域倒数 30 门店 + 温层。
4. 所有 KA 的大区 / 省区统一排名。

依赖维表：

- 门店维表：系统、门店编码、门店名称、是否 DC、大区、省份、城市、内外区、门店状态。
- 商品维表：系统商品编码、条码、统一商品名称、规格、温层、产品线、口味、是否核心品。

### P2：依赖新增源数据后上线

1. 完整 KA 大盘出货数据。
2. 单品出货额与 POS 额对比。
3. 沃尔玛每日退货、当月累计退货、退货 / 进货比例。

原因：当前只有盒马、家得福、大润发部分字段能表达入库 / 进货 / 待收；沃尔玛缺退货和进货发生数据，永辉、比优特、天虹也缺稳定出货源。

## 6. 待确认问题

1. `出货` 的业务定义：是供应商发货、KA 入库、门店收货，还是系统里的日收 / 月收 / 进货？
2. 销售金额是否统一用含税口径？沃尔玛部分报表标注未税，需单独换算或保留未税标签。
3. PSD 分母是否统一为“有库存门店数”，还是“总门店数 / 动销门店数”？
4. 周转天数的 7 天平均是否包含数据日？建议用 D-7 至 D-1，避免当天销售未完整导致偏差。
5. 周转超 60 天门店数是否排除 DC、小店、闭店、门店状态非开业门店？
6. 大润发内区 / 外区、温层、省份归属是否已有标准维表；如果没有，需要先建维表。
7. 沃尔玛退货和进货是否能从另一个系统导出；当前工作簿不能直接计算退货率。

### `ads_ka_daily_metrics`

在事实表基础上按日期、系统、大区、门店、商品、渠道汇总，输出：

- 销售数量、销售金额、出货数量、出货金额、退货数量、退货金额。
- 门店库存、DC 库存、总库存、在途库存。
- 近 7 日平均销量、PSD、库存周转天数。
- 动销门店数、有库存门店数、超 60 天门店数。
- 销量占比、销售额占比、销量排名、销售额排名、环比增长率。
