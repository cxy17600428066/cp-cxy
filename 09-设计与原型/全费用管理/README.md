# 全费用管理交互原型

- 原型入口：[原型.html](./原型.html)，可直接用浏览器打开，无需启动服务。
- 规则文档：[全费用管理规则建议稿 V1](../../05-产品方案/脱骨侠全费用管理规则建议稿V1.docx)。
- `rules.json` 为规则数据，`build_deliverables.py` 为生成脚本，Word 输出至工作区 `05-产品方案`。
- `qa/` 保留排版预览与浏览器检查结果；`qa.mjs`、`qa_multipoool.mjs` 为演示流程验收脚本。
- `render_word.ps1` 使用本机 Word 导出内部排版预览。

原型包含客户台账、政策草稿、销售费用试算、组织费用池、活动与核销、审核工作台、结算清偿、异常对账和规则说明。所有数据与角色均为演示，不连接真实业务系统。

按工作区既有分类归档：规则设计文档放在 `05-产品方案`，交互原型及其配套资源放在 `09-设计与原型`。
