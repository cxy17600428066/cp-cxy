# 销售计划管理功能梳理

来源：销售计划管理调整会议纪要，2026-10-12整理。目标：贯通月周计划、审核、调整和订单达成。

| 编号 | 需求 | 优先级 | 当前交付 |
| --- | --- | --- | --- |
| SP01 | 线上线下月周差异粒度填报 | P0 | 交互原型 |
| SP02 | 开放截止与补报授权 | P0 | 演示窗口，生产时点待确认 |
| SP03 | 分级汇总与最终确认 | P0 | 审核节点与意见记录 |
| SP04 | 可填报商品范围 | P0 | 商品维护和有效期控制 |
| SP05 | 参考历史销售 | P1 | 时间范围入口，真实数据待接入 |
| SP06 | OA加急增减与版本 | P0 | 演示审批，附件保留名称 |
| SP07 | 双向订单关联与异常处理 | P0 | 同维度匹配及手动处理 |
| SP08 | 多维达成与归档 | P0 | 共用数据大屏下钻 |

价值：避免客户级月计划、售后未定口径和重复关联造成失真；业务投入集中在数据源、组织权限与计入口径确认。详细开发边界见专题PRD。
