# 线上 / 线下数据展示

管理页和达成大屏统一提供线上、线下独立入口，不提供混合统计选项。

- 已确认需求总表、标准生产需求、月周对照、来源明细和导出均按当前业务取数，同商品不跨业务相加。
- 月度、周计划保留独立入口。线下为省区 / 客户 / 商品，线上为渠道 / 商品。
- 线下逐级审核与线上丹总审核保持原有流程；待审核、已审核数量分别取当前业务。
- 数量调整、订单关联、适用商品、通知与待办按业务分开。共用商品可同时出现在两侧。
- 达成分析按表格展示；线上显示渠道、商品，线下显示中心、大区、省区、客户、商品。
- 人员业务入口按角色限制；公共规则和包装换算仍为共享配置，不复制为两份冲突规则。

验证命令：`node 线上线下区分-验收.cjs`；原有六项回归验收亦通过。
