# HTML 原型说明

当前需求和操作以 [README](./README.md) 与 [V4 PRD](./07-销售计划管理PRD.md) 为准。

交付是纯 HTML/CSS/JS 原型，复制整个文件夹，推荐同源本地 HTTP 使用。入口 14 为管理、15 为达成大屏、16 为历史销量查询，共享本地数据。无需后端。

核心流程：发布应填清单和窗口→销售整单提交→线下大区/中心/严总或线上丹总审核→计划部门确认后生效。普通数量调整无 OA，仅计划部门确认；其他开始前内容变更重新经过销售审核与确认。原执行版本在确认前不变。

可在“全流程演示”补充十个固定批次闭环样例，并点击节点直接查看。模拟样例不代表真实业务，不覆盖用户已有计划。规则未确认时页面明确阻止提交或正式达成计算，具体见 PRD 和验收记录。
