# 脱骨侠物流 H5 功能清单

版本：V1.0　整理日期：2026-08-05

## 1. 角色与权限

| 编号 | 角色 | 功能 | 规则说明 | 优先级 |
|---|---|---|---|---|
| R-01 | 工厂物流 | 姓名账号＋密码登录 | 姓名作为工厂账号，输入账号和密码登录；账号、密码及启停状态由管理员维护 | P0 |
| R-02 | 货车司机 | 手机号登录 | 输入手机号和短信验证码，按照手机号查询已绑定发货单 | P0 |
| R-03 | 甲方 | 手机号登录 | 输入预留手机号和短信验证码，按照手机号查询收货订单 | P0 |
| R-04 | 全角色 | 退出登录 | 清除当前登录身份，返回角色选择页 | P0 |
| R-05 | 全角色 | 数据隔离 | 只能查看当前账号或手机号有权限访问的订单 | P0 |
| R-06 | 工厂物流 | 全流程查看 | 可查看订单、发货、揽收、签收、甲方确认结果 | P0 |
| R-07 | 货车司机 | 节点权限 | 只可查看和操作揽收、签收节点 | P0 |
| R-08 | 甲方 | 验收权限 | 只可查看绑定订单、物流详情并完成确认收货 | P0 |

### 8.1 全链路控制补充

| 编号 | 功能 | 规则说明 | 优先级 |
|---|---|---|---|
| W-01 | 创建与发货分离 | 创建发货单后进入待发货；工厂完成逐商品数量、附件、司机车辆和凭证核验后才能确认发货 | P0 |
| W-02 | 逐商品数量链 | 订单计划、工厂发货、司机揽收、司机到货、甲方签收分别保存每个SKU实际箱数并自动汇总 | P0 |
| W-03 | 数量差异工单 | 任一SKU数量与上一节点不一致时，强制选择异常类型、填写原因并上传照片，自动生成异常工单 | P0 |
| W-04 | 部分签收与拒收 | 支持短少、错货、破损、部分签收和拒收，异常闭环不覆盖原履约数据 | P0 |
| W-05 | 资质拦截 | 驾驶证、车辆年检或冷链资质过期，或公司/司机停用时禁止发货选择 | P0 |
| W-06 | 节点通知 | 创建、司机变更、发货、揽收、到货、待确认、异常和完成节点通知相关角色 | P1 |
| W-07 | SLA超时 | 超过预约揽收、预计到货或甲方确认时间时自动提醒并在前后台标红 | P1 |
| W-08 | 防重复提交 | 节点提交使用唯一幂等键，提交中锁定按钮，网络重试不能生成重复记录 | P0 |
| W-09 | 二维码安全 | 二维码令牌支持限频、作废、重新生成；重新生成后旧令牌永久失效 | P0 |

## 11. 当前原型与正式系统边界

- 当前 H5 与后台为前端交互原型，页面刷新后新增数据、照片和状态会恢复。
- 短信验证码、定位、二维码、文件存储和身份绑定为模拟交互。
- 正式开发需接入订单系统、用户身份服务、短信服务、对象存储、定位服务、数据库和操作日志。
- 正式系统必须由后端根据登录身份查询订单绑定关系，禁止前端直接传手机号获取任意订单。
